# 1. 总览与设计原则

## 1.1 定位

玩家 = 国家意志。建筑与经济系统是玩家在"没有个人部队、没有个人 RPG 玩法"之后的主要经营玩法，同时为战争提供后勤与战斗力来源。

**经济服务于战争，不是第二个游戏。**

## 1.2 核心循环

```
国策解锁 → 建造（材料 + 时间）→ 产出商品 → 市场平衡（价格 / 收入 / 军需）
      ↑                                                        ↓
      └──────────── 税收 / 国库 / 再投资 ←──────────────────────┘
```

## 1.3 设计原则

| 类别 | 内容 |
|---|---|
| 抄（维多利亚 3 骨架） | 建造点池、建造队列、每建筑进度上限、三档建造部门（单位成本递减）、价格公式、缺料停产、私有制、破产链条、国有化 |
| 简化 | 不做人口/生活水平/利益集团/法律/科技树/基建/运输网/公司/投资池账本；市场只做全国+城市两层；商品控制在 17 种 |
| 不做 | 世界市场/贸易优势/禁运矩阵/商船/港口封锁；现金储备账本；10 年破产衰减（压缩为 30 天） |
| 时间尺度 | 全部按**天**结算（维多利亚按周） |
| 可调性 | 所有数值集中在配置表，支持游戏内 flags 覆盖，便于平衡 |

## 1.4 维多利亚 3 概念映射

| 维多利亚 3 | 本 mod |
|---|---|
| 州 / 省 | 定居点（城 / 堡 / 村） |
| 建筑等级 | 建筑数量（堆叠） |
| 生产方法（PM） | 木 / 石 / 铁 三模式（隔天生效） |
| 建造部门 | 建造部门（木 / 石 / 铁） |

| 全国市场 | 全国大市场 |
| 本地价 / MAPI | 城市小市场（本地价 = 全国价 × 本地稀缺系数） |
| 短缺 | 缺料 = 停产（不采用渐进惩罚） |
| 投资池 | 领主个人金钱（简化） |
| 国有化 / 私有化 | 国有化（花钱买断）/ 破产强制私有化 |

# 2. 建筑系统

## 2.1 建筑组数据模型

每个定居点、每种建筑 = 一个建筑组：

```
BuildingGroup {
    string   DefId;         // 建筑定义 id
    int      Count;         // 已建数量（堆叠）
    BuildingMode Mode;      // Wood / Stone / Iron
    List<QueuedBuild> Queue;// 在建队列（每个元素 = 1 个单位）
}

QueuedBuild {
    int    Progress;        // 已投入建造点
    int    TotalWork;       // 总工时（由模式决定）
    int    Index;           // 队列位置
    bool   Paused;
}
```

- 模式对该组**全部数量**生效
- 模式切换**隔天生效**，免改造、免费用
- 建筑没有等级，只有数量堆叠（用户决策）

## 2.2 三种模式

| 模式 | 产出倍率 | 单位维护倍率 | 附加材料消耗 | 可建门槛 |
|---|---|---|---|---|
| 木制 | ×1.00 | ×1.00 | 无 | 有木制部门即可 |
| 石制 | ×1.50 | ×0.70 | 石料 | 有石制部门 |
| 铁制 | ×2.30 | ×0.45 | 石料 + 铁 | 有铁制部门 |

**规则说明**
- 附加材料消耗按建筑基准产出折算，见第 12 章数值表
- "越高级 = 效率越高、单位成本越低、吃料越高级"（用户决策）
- 缺料（任一输入商品库存不足）→ 当日**停产**，产出为 0，状态显示"缺料"
- 建筑停产不影响维护费（维护费照扣，作为压力）
- 围城 / 掠夺期间所有建筑停产；城易手后建筑保留（含模式与数量）

## 2.3 槽位与上限

| 地点 | 公式 | 上限 |
|---|---|---|
| 城镇 | 4 + 繁荣度 / 1000 | 12 |
| 城堡 | 3 + 繁荣度 / 1500 | 8 |
| 村庄 | 1 + 户数 / 500 | 5 |

- 已建 + 在建 都占槽位
- 每种建筑**不设单独数量上限**，只受槽位总上限限制
- 槽位每日结算时刷新（繁荣/户数变化会改变上限）

| 归属 | 可建类别 | 谁操作 | 盈亏 |

| 国有 | 全部 | 玩家 | 国库 |

## 2.7 建造 / 拆除 / 取消规则

| 操作 | 规则 |
|---|---|
| 建造 | 排队 → 占槽位 → 每日投入建造点与材料 → 完成后 Count+1 |
| 拆除 | 立即，退还 50% 材料（按当前模式造价） |
| 取消在建 | 退还 50% 已投入材料，进度清零 |
| 暂停队列项 | 保留进度，不消耗建造点与材料 |
| 队列重排 | 自由上移 / 下移 |
| 队列长度 | 每定居点最多 5 项 |

| 地点 | 预置内容 |
|---|---|

| 每个村庄 | 若特产不是粮食，额外预置 1 个**农田**（数量 1、木制），保证温饱 |

# 3. 建造部门与建造流程

## 3.1 建造部门

| 档 | 建造点 / 日 | 每日消耗 | 可建建筑档次 |
|---|---|---|---|
| 木制 | 5 | 木材 3 | 木档 |
| 石制 | 9 | 木材 3 + 石料 2 | 木 + 石档 |
| 铁制 | 14 | 木材 3 + 石料 2 + 铁 1 | 全部（铁档） |

- 部门本身是建筑，占槽位
- 部门可通过切换模式升级（木→石→铁，隔天生效）
- 部门可拆除（不退材料）
- **没有部门的定居点不能开工**（用户决策）
- 建造点**每城独立池**（用户决策）：本地部门只服务本地

## 3.2 建造点结算

```
城市建造点池 = Σ(本地部门数量 × 档位点数) × 材料供给系数
材料供给系数 = min(1, 当日可获得材料 / 当日需要材料)
```

- 每日结算一次
- 建造点不累积（当日不用即浪费）
- 队列按顺序消耗建造点；每项每日最多投入 = 其工时 × 20%（防独占）

## 3.3 队列规则

1. 每个定居点一条队列，最多 5 项
2. 每项可上移 / 下移 / 暂停 / 取消
3. 队列项每日结算：先采购当日材料，再投入建造点
4. 材料买不到 → 当日停滞（显示"缺料"），进度不倒退
5. 从队列移除 → 进度清零，退还 50% 已投入材料

## 3.4 每日结算流程（建造部分）

```
1. 计算本地建造点池（含材料供给系数）
2. 按队列顺序遍历每一项：
   a. 计算当日需要材料 → 从本地市场买 → 不足则从全国市场调运 → 再不足则进口
   b. 材料到位 → 投入建造点（上限 = 工时 × 20%）
   c. 进度 += 投入点数 × 建造效率
   d. 进度 >= 工时 → 完成，Count+1，释放队列项
3. 刷新槽位与 UI
```

## 3.5 材料采购优先级

1. **本地城市市场**（价格最低）
2. **全国市场调运**（+10% 运费，1 天到货）
3. **进口**（+30% 溢价，2 天到货）
4. 都买不到 → 停滞

## 3.6 建造效率修正

| 来源 | 修正 |
|---|---|
| 动乱 | −20% |
| 被围城 / 掠夺 | −50% |
| 破产（30 天内） | −75% |
| 国策加成（后期） | 按国策定义 |
| 最低值 | 5% |

# 5. 市场系统

## 5.1 两层结构（用户决策）

```
全国大市场（汇总视图 + 基准价 + 跨城调运中心）
  ├── 城市小市场（每城镇一个）
  │     └── 挂靠村庄（原版 Village.TradeBound，用户决策"用原版"）
  └── 城堡：无市场，挂靠原版 TradeBound 城镇
```

- 村庄产出进入其 `TradeBound` 城镇的小市场
- 城堡的产出 / 消耗也走其 `TradeBound` 城镇
- 全国大市场 = 所有城市小市场的汇总（自动聚合，无需连接建筑）

## 5.2 价格公式（照抄维多利亚）

```
市场价 = 基础价 × [1 + 0.75 × clamp((买 − 卖) / min(买, 卖), −1, +1)]
```

- 价格区间：25% ~ 175% 基础价
- 每日价格变动幅度 ≤ 10%（平滑）
- 本地价 = 全国基准价 × 本地稀缺系数

```
本地稀缺系数 = clamp(1 + (本地需求 − 本地供给) / max(本地需求, 本地供给, 1), 0.5, 1.5)
```

## 5.3 库存与供需

每个城市小市场记录每种商品：

| 字段 | 说明 |
|---|---|
| 库存 | 当前存量 |
| 日产出 | 本地建筑产出之和 |
| 日消耗 | 本地建筑消耗 + 军队消耗 + 民生消耗 |
| 本地价 | 见 5.2 |
| 缺口 | max(0, 需求 − 供给) |

- 建筑买卖优先在本地市场成交
- 本地买不到 → 全国调运 → 进口
- **缺料 = 停产**（用户决策，不采用维多利亚的渐进惩罚）；市场面板仍显示短缺标记供玩家查看

## 5.4 跨城调运

- 触发条件：城市间价差 > 20%
- 每日容量 = Σ(本地"市场"建筑等级 × 10)
- 运费：+10%（计入买家成本）
- 到货时间：1 天
- 调运方向：价差大的优先

## 5.5 进出口

- 入口：有"贸易站"建筑的城市
- 容量 = Σ(贸易站 × 30) / 日
- 进口溢价：+30%
- 到货时间：2 天
- 关税：玩家可设 0% / 12.5% / 25%（按基础价计算），首版默认 0%

## 5.6 生活用品 → 繁荣度循环

| 商品 | 效果 |
|---|---|
| 布 / 工具 / 酒 / 陶器 | 在城市市场售出时，按销量提升定居点繁荣度 |
| 繁荣度提升 | 每 100 单位售出 → +1 繁荣度（每城每日上限 +2） |
| 过剩 | 价格下跌 → 建筑亏损（国有 = 国库承担，私有 = 领主承担） |
| 短缺 | 粮食短缺 → 繁荣度下降、忠诚下降 |

## 5.7 市场面板（图三样式）

- 入口：左侧栏按钮 + 城镇抽屉内的"市场"按钮
- 页签：商品 / 贸易
- 商品表列：图标 / 名称 / 价格 / 变化% / 供给 / 需求 / 库存 / 缺口
- 支持按价格、缺口排序
- 显示全国汇总与当前选中城市两套数据

# 6. 国库、借债与破产

## 6.1 国库定义（用户决策）

- 国库 = 玩家（国家意志）金钱
- **允许为负数 = 债务**（破产机制的前提）
- 无金库上限（用户决策）

## 6.2 收入与支出

| 收入 | 支出 |
|---|---|
| 定居点税收 | 建筑维护费 |
| 国有建筑产出出售 | 建造材料采购 |
| 关税 | 军费（军队维护） |
| 战利品 / 赔款 | 进口费用 |
| 国有化费用 | 借债利息 |

## 6.3 借债与利息

- 国库 < 0 时自动进入借债状态
- 利息：基础 20% / 年（约 0.055% / 日），可被"银行"建筑与国策降低
- 利息每日结算，计入支出
- 国库 ≥ 0 时自动优先还债

## 6.4 破产（用户决策：全部惩罚都要）

**触发**：国库 < 0 持续 **7 天**

**破产惩罚（全部执行）**

| # | 惩罚 |
|---|---|
| 1 | 清空全部债务（国库归 0） |
| 2 | 取消所有在建项目（不退材料） |
| 3 | **债务下发领主**：按家族财富比例，每家族每日扣钱，直到债务还清 |
| 4 | 领主关系 −20、领主忠诚 −10 |
| 5 | 军队士气 −20（30 天衰减）、军队战斗力 −25%（30 天） |
| 6 | 全国建造效率 −75%（30 天） |
| 7 | **强制私有化**：经济类（资源/加工/贸易/后勤/民生）国有建筑转给本国领主（随机分配） |

**债务分摊公式**

```
某家族每日扣款 = 债务总额 × (该家族财富 / 全国领主总财富) × 0.02
债务总额 = 破产时国库缺口 × 2（惩罚性）
扣款持续到债务还清或家族破产（家族金钱归 0 则跳过）
```

**恢复条件**：债务还清 + 国库 ≥ 0

## 6.5 破产警告

- 国库 < 0 第 1 天起，屏幕顶部显示红色警告条："国库亏空 X 第纳尔，Y 天后破产"
- 市场面板与建筑列表顶部同样提示

# 7. 私有建筑与领主 AI

## 7.1 领主性格

每名领主开局随机分配一种性格：

| 性格 | 行为倾向 |
|---|---|
| 保守 | 只建已有建筑的补充，不尝试新类别 |
| 进取 | 偏好加工 / 工业类 |
| 军事 | 偏好军营 / 军械库 / 马厩 |
| 商贸 | 偏好市场 / 贸易站 / 驿站 |
| 懒惰 | 建造概率极低 |
| 贪婪 | 只建预估利润最高的建筑 |

## 7.2 建 / 关决策（用户决策：性格 + 盈亏）

每 7 天评估一次：

```
对每个领主：
  1. 找到其封地（定居点）
  2. 若本地槽位有空 且 领主金钱 > 建造成本 × 2：
     a. 按性格权重选择候选建筑
     b. 预估利润率 = 预估产出价值 / (维护 + 材料) 
     c. 利润率 > 性格阈值（保守 1.5 / 进取 1.2 / 军事 1.0 / 商贸 1.2 / 懒惰 3.0 / 贪婪 2.0）
     d. 通过则排队建造（使用领主个人金钱）
  3. 对已建私有建筑：
     - 连续 30 天亏损 且 性格非保守 → 拆除（退还材料归领主）
     - 连续 15 天缺料 → 切换模式（降档）
```

## 7.3 资金

- 领主使用**个人金钱**（用户决策）
- 建造成本（材料 + 人工）直接从领主金钱扣除
- 私有建筑收益（产出售出）进入领主金钱
- 领主金钱 < 0 → 自动关闭最亏的私有建筑

## 7.4 国有化

- 玩家在建筑列表对私有建筑点击"国有化"
- 价格 = 造价 × 1.5（未建成按进度折算）
- 从国库支付给领主
- 国有化后归玩家操作

# 8. 军需与战斗力

## 8.1 军需消耗（用户决策 A+B+C）

每 100 名士兵每日消耗：

| 商品 | 数量 |
|---|---|
| 粮食 | 2 |
| 武器 | 0.4 |
| 盔甲 | 0.3 |

- 从军队所在位置最近的己方城市市场扣减
- 市场不足 → 从全国调运 / 进口
- 都买不到 → 供给率下降

## 8.2 供给率

```
粮食供给率 = min(1, 实际供应 / 需要)
武器供给率 = min(1, 实际供应 / 需要)
盔甲供给率 = min(1, 实际供应 / 需要)
总供给率 = min(三者)
```

## 8.3 作用 A：自动结算

```
自动结算战斗力系数 = 0.75 + 0.5 × 供给率
（供给 0% → ×0.75；供给 100% → ×1.25）
```

作用于大地图自动战斗（`MapEvent` 结算）。

## 8.4 作用 B：手动战斗（用户确认的推荐方案）

- 战斗开始时（`Mission` 初始化），对玩家一方所有士兵应用：

```
攻击倍率 = 0.90 + 0.20 × 供给率
护甲倍率 = 0.90 + 0.20 × 供给率
```

- 实现方式：`AgentDrivenProperties` 的 `AttackDamageMultiplier` / `ArmorEffectiveness` 乘系数
- 敌军（AI 国家）同样按各自的供给率计算
- 战斗内 UI 不显示具体数值（保持沉浸）

## 8.5 作用 C：士气 / 补给 / 行军

| 项 | 公式 |
|---|---|
| 士气 | + (供给率 − 0.5) × 10 |
| 行军速度 | × (0.90 + 0.20 × 供给率) |
| 补给消耗 | 供给率 < 50% 时，军队每日损失 1% 兵力（逃兵） |

# 9. AI 国家

## 9.1 市场自动平衡

每 7 天：

1. 扫描本国各城市市场缺口
2. 缺料建筑 → 切换更低模式（降档保产）
3. 过剩商品 → 切换更高模式（提效）
4. 严重缺口 → 进口
5. 过剩 → 出口

## 9.2 自动建造

每 7 天：

1. 按缺口权重生成候选（粮食缺口 > 军需缺口 > 建造材料缺口 > 民生）
2. 检查国库（AI 国家的国库 = 其统治者金钱）
3. 国库不足 → 减速（跳过本轮）
4. 建造使用其自身建造部门与建造点

## 9.3 安全阀（防崩）

- 价格带宽限制在 25%~175%（公式天然保证）
- 粮食保底：AI 国家每城至少 1 个农田（不足时优先补）
- AI 破产简化：不执行强制私有化，只减速 30 天

## 13.2 接管原版村庄产出

1. 用 apidump 定位村庄产出入口（候选：`Village.DailyTick`、`Settlement.DailyTick`、`CampaignEventDispatcher` 村庄事件）
2. Harmony patch 前缀：玩家国家所属村庄 → 跳过原版产出
3. 产出改由本系统结算（预置建筑 + 玩家建筑）
4. AI 国家村庄：保留原版产出或同样接管（首版保留原版，减少变量）

## 13.3 性能预算

| 项 | 规模 | 说明 |
|---|---|---|
| 日结算 | ~100 定居点 × 17 商品 = 1700 次 | 每日一次，可接受 |
| 市场调运 | O(城市数² × 商品) | 用价差排序优化 |
| UI 刷新 | 数据变化才刷新 | 脏标记 |
| 地图徽标 | < 100 个 | 每帧投影 |

# 15. 风险与回退

| 风险 | 应对 |
|---|---|
| 接管原版产出导致经济崩溃 | 预置建筑 + 粮食保底 + 安全阀；可一键回退（flags） |
| 性能（日结算） | 每日一次；必要时分帧计算 |
| UI 工作量大 | 复用现有 prefab 与笔刷；分期交付 |
| 存档兼容 | 版本号 + 自动初始化 |
| AI 经济崩坏 | 安全阀 + 简化规则；AI 破产只减速 |
| 数值失衡 | 全部数值可配置，快速迭代 |
