# 内政与经济扩展（FeudalInternalAffairs）

《骑马与砍杀 2：霸主》(Bannerlord) **v1.4.8** 的独立 mod。

玩家设定：**你是国家意志本身**——没有个人部队，取而代之的是在内图上直接指挥全国的部队、调度经济、驾驭政治、以谈判桌开启战争。

> 本 mod 与 `_FeudalCalradia` 互斥，不能同时启用（两者都改了地图与 UI 层）。

## 核心玩法

### 经济（全图模拟，所有国家都在跑）
- **建筑与建造**：村庄/城堡/城镇各有一批建筑（资源/加工/军事/行政/贸易/物流/生活），有规模、到岗率、现金、所有者；材料→建造点→完工；围城/动乱/破产会减产停产。
- **商品与市场**：约 20 种中世纪商品，全图统一价按维多利亚 3 公式每日浮动（±75% 钳制、跨市场价差 MAPI），库存/日耗/日产量驱动价格。
- **人口**：按（定居点 × 职业 × 文化）模拟 15 类职业；有需求买包、财富=生活水平、激进度、忠诚度；每周迁移与人口增长。
- **税制**：土地税/人头税/什一税/市场税，各五档（免征→苛征）；税负过重会推高激进、压低工商与吸引力。
- **钱庄信贷**：信用额度、月息 3%~12%；超额度 7 天被领主讨债、14 天破产（清债 + 激进暴涨）。
- **铸币权**：铸币厂 + 银矿 → 铸币收入；成色越差收入越高但物价越贵（通胀）。
- **行会与特许状**：5 类行会加成；王室特许状给垄断加成，行会按月上缴年金。
- **所有权与分红**：王室/领主/教会/行会/私人五类所有者，分红进国库或各池；可赎买/没收/出售建筑。
- **统计**：30 天滚动账本（税收/关税/铸币/分红/利息/工资/材料/进出口/人口/物价指数）。

### 政治（领主为首）
- **领主档案**：势力、态度、愤怒、恐惧、御前会议席位、倾向（王室/贵族/教权/市民）。
- **三大资源**：权威（行动力）、合法性（统治根基）、暴政（没收/处决积累）。
- **法令**：王位继承/税赋特权/军务征召/教产保护/商贸特许/王室司法，各三级；领主大会按势力加权表决，可花双倍权威"强推"。
- **御前会议五席**：首相/掌玺/财政/军务/司法，各有全被动加成。
- **请愿**：减税/赔偿/平抑物价/特许/加什一/授勋；同意要付代价，拒绝或拖延会积累愤怒。
- **派系阶梯**：不满→请愿→最后通牒→抗命（领地减产、拒税）→内战（可镇压或妥协）。
- **民众叛乱**：市民愤怒过高且合法性崩坏时，用**原版叛乱系统**在忠诚最低的城镇点燃民变。

### 外交博弈（所有战争先谈判）
- 向邻国发出**宣战诏书**即开启博弈：诉求=割地/赔款/纳贡/羞辱/通商，第一条免费。
- **机动点**按国格分配，用于加诉求与**拉拢第三国**（提供义务/赔款分成/开放商路/割让征服地/扶植附庸/当场佣金，附接受预估）。
- 三阶段：落子 → 外交操作 → 开战倒计时；对方可**屈服**（主要诉求立即生效）或死磕到底。
- **恶名**会压低所有国家对你的关系；**战时支持度**归零即投降（敌方诉求全部执行）；停战按「军力 × 支持度」判胜方执行诉求。
- 附庸按月纳贡、通商国贸易 +25%、被羞辱方 5 年不能主动对你开博弈。
- 同盟体系：盟友自动参战；AI 的战争也走同一套博弈系统（原版战争/和平决议已被替换）。

### 军事（国防军）
- **募兵与征兵**：在军务页向本国城镇/村庄募兵（人 / 钱 / 装备三要素），兵员进入该城**守备营**（不与原版驻军混淆统计）；立法后可开启征兵法令从平民池征召。
- **野战军团**：从守备营抽调兵员组建（编制含将军：N 人 = 1 名将军 + N-1 名士兵），**无人数上限**；速度恒定，军饷按兵力从国库支出。
- **全听玩家指挥**：国防军不参与原版 AI（不会自己溜达、不自动征兵、不擅自交战目标）；选中后左键点地图即移动，底层不驱动时由 mod"手动驾驶"保证按期到达；右键菜单可下达驻防 / 巡逻 / 补员 / 解散 / 拆分。
- **军团任务**：驻防（回驻地，允许进城）、巡逻（驻地周边绕圈）、补员（从守备营调兵）、拆分 / 合并（框选多支后右键）。
- **驻军与出城**：点城市弹出**驻军列表**（原版驻军合计 / 国防军守备营 / 城内我军），可一键 [出城]、[唤出军团]（守备营 ≥100 编成新军团，否则召唤最近联军）、[查看建筑]。
- **军队总览页**：导航栏【军队】汇总全国武装力量：国防军（绿）、领主军（金）、联军（合并显示），行内 [定位] 跳转指挥；联军行 [操纵] 进入**军团操作页**：命令某支部队出军团 / 解散军团。
- **战争经济**：各国有军需、金库、平民池；饥荒 / 破产 / 兵源枯竭会掉士气、逃兵并影响 AI 的宣战与和谈决策；国防军有独立军饷与喂粮系统。
- **厌战度**：战争伤亡与时间累积，高厌战会逃兵、拖累繁荣并促使 AI 求和；地图模式可直接查看各国厌战度。

### 界面与指挥
- 左侧 **导航栏 14 格**：国家 / 人口 / 建筑 / 市场 / 外交 / 国策 / 财政 / 社会 / 行会 / 统计 / 政治 / 博弈 / 军务 / 军队，全部骑砍风面板。
- **重开新档**：进入战役地图后**地图选国**（点领地或右侧栏选国家 → 开始游戏），自动跳过角色创建页与开场视频。
- **地图指挥**：框选本国部队、左键选中后点地图移动 / 点敌军攻击 / 点城市前往或围城；右键对选中国防军下达任务。
- **RTS 战斗指挥**：亲自指挥时切换为 RTS 视角（WASD 平移、滚轮缩放、Tab 切换兵种标记）。
- **国策树**：HOI4 式节点树（17 个示例节点，可由内容作者按模板扩充）。
- **国家意志**：接管所选国家、禁用 AI 外交自主行为（战争/和平/贸易协定/同盟均走本 mod 接口）；消息流会避让导航栏与侧边栏，避免遮挡。

## 安装

1. 游戏版本 **v1.4.8**，并安装前置 mod：**Bannerlord.Harmony**、**Bannerlord.UIExtenderEx**。
2. 将 `_FeudalInternalAffairs` **整个文件夹**放入
   `Mount & Blade II Bannerlord\Modules\`
   （**只保留一个文件夹**；RTS Camera 源码已内嵌，无需另装）。
3. 启动器中勾选 **内政与经济扩展**。

> 说明："RTS 战斗指挥"已固定启用 RTS 式视角，无需任何切换开关。

## 从源码构建

```bash
dotnet build FeudalInternalAffairs.csproj -c Release
```

产物在 `bin\Win64_Shipping_Client\FeudalInternalAffairs.dll`。

游戏目录默认路径可在 `FeudalInternalAffairs.csproj` 的 `GameModulesDir` 中调整，或构建时覆盖：

```bash
dotnet build FeudalInternalAffairs.csproj -c Release -p:GameModulesDir="你的路径\Modules"
```
